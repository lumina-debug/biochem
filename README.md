# biochem — 生化学 長文穴埋め問題サイト

各講義のまとめ（PDF／Markdown）をもとに作成した、**生化学の長文穴埋め問題**を出題する Web サイトです。

## 収録内容

`docs/questions.js` に、以下 7 章・全 32 問・空欄 182 個の問題を収録しています。

| 章 | テーマ |
|---|---|
| 序論 | 代謝の通貨・熱力学・高エネルギー化合物・区画化 |
| 解糖 | 10 反応・収支・調節（PFK-1）・発酵・他の単糖 |
| PPP | ペントースリン酸経路・NADPH・G6PD 欠損症 |
| 糖新生 | 4 つの迂回反応・F2,6BP による相反制御・コリ回路 |
| 調節 | PFK・PFKFB・PK・LDH アイソザイム・がん代謝 |
| 輸送 | HK/GK・GLUT・SGLT・SGLT2 阻害薬・糖尿病 |
| 制御 | PEPCK・ホルモンシグナル（CRTC2）・臓器連関 |

## 機能

- **章別／全範囲**のランダム出題
- **記述モード**：空欄に用語を入力（英語表記・ハイフン有無・別名などの表記ゆれを吸収して採点）
- **選択モード**：語群からクリックで空欄を埋める
- 空欄ごとの正誤表示・正答の提示、設問ごと／セッション全体のスコア集計
- ライト／ダークテーマ切替、スマホ対応

## 使い方

### そのまま開く
`docs/index.html` をブラウザで開くだけで動作します（外部依存なし・オフライン可）。

### ローカルサーバで開く
```bash
cd docs
python3 -m http.server 8000   # → http://localhost:8000
```

### GitHub Pages で公開する
リポジトリの Settings → Pages で、Branch を本ブランチ、フォルダを `/docs` に指定すると公開できます。

## ファイル構成

```
docs/
├── index.html     # 画面（ホーム／出題／結果）
├── styles.css     # デザイン（ライト・ダーク対応）
├── app.js         # 出題・採点ロジック
└── questions.js   # 問題データ（ここを編集すれば問題を追加・修正できます）
```

## 問題の追加・編集

`docs/questions.js` の `questions` 配列に、以下の形式で追加します。文字列はそのまま本文、
オブジェクトが空欄です。`a` が正答、`alt` は別解（採点時に正規化して照合）、`hint` は任意のヒントです。

```js
{
  id: "glyco-8", chapter: "glyco", title: "問題タイトル", source: "解糖 §X",
  segments: [
    "解糖の律速酵素は",
    { a: "PFK-1", alt: ["ホスホフルクトキナーゼ-1", "phosphofructokinase-1"] },
    "である。"
  ]
}
```
