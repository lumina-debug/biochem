## 解説

各問題には**解説**が付いており、採点すると空欄一覧の下に「解説」パネルが表示されます。試験で問われる「なぜ・どう制御され・何のために」の流れを短くまとめています。解説は `docs/questions.js` 末尾の解説マップ（`id` → 解説文）で管理しています。

## 機能

- **章を選ぶたびに、その章の問題がランダムな順で出題**（全範囲もランダム）
- **記述モード**：空欄に用語を入力。**英語表記・略称・別名・言い換え・仮名ゆらぎを許容**し、表記ゆれ（ハイフン・空白・長音・全角半角・大小文字）を吸収して採点。**すべて英語で答えても正解**になります（例：クエン酸 → citrate / citric acid）
- **選択モード**：語群からクリックで空欄を埋める
- **採点時に「解答と別解」を一覧表示**（各空欄の正答・あなたの解答・許容される別解）
- 空欄ごとの正誤表示、設問ごと／セッション全体のスコア集計
- ライト／ダークテーマ切替、スマホ対応

## 使い方

### そのまま開く
`docs/index.html` をブラウザで開くだけで動作します（外部依存なし・オフライン可）。

### ローカルサーバで開く
```bash
cd docs
python3 -m http.server 8000   # → http://localhost:8000
```

### GitHub Pages で公開する
リポジトリの Settings → Pages で、Branch を本ブランチ、フォルダを `/docs` に指定すると公開できます。

## ファイル構成

```
docs/
├── index.html     # 画面（ホーム／出題／結果）
├── styles.css     # デザイン（ライト・ダーク対応）
├── app.js         # 出題・採点ロジック
└── questions.js   # 問題データ（ここを編集すれば問題を追加・修正できます）
```

## 問題の追加・編集

`docs/questions.js` の `questions` 配列に、以下の形式で追加します。文字列はそのまま本文、
オブジェクトが空欄です。`a` が正答、`alt` は別解（採点時に正規化して照合）、`hint` は任意のヒントです。

```js
{
  id: "glyco-8", chapter: "glyco", title: "問題タイトル", source: "解糖 §X",
  segments: [
    "解糖の律速酵素は",
    { a: "PFK-1", alt: ["ホスホフルクトキナーゼ-1", "phosphofructokinase-1"] },
    "である。"
  ]
}
```
